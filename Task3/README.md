Итог выполнения домашнего задания

В рамках работы был реализован полный пайплайн анализа данных секвенирования и оценки качества картирования ридов.

1. Подготовка окружения

Была использована операционная система macOS и язык командной строки bash.

Установлены необходимые инструменты:

FastQC — контроль качества ридов
BWA — выравнивание ридов на референс
SAMtools — работа с SAM/BAM и оценка качества картирования
FreeBayes — поиск генетических вариантов
SRA Toolkit — загрузка данных из NCBI

2. Данные

В качестве входных данных использовались:

референсный геном Escherichia coli (E. coli)
набор секвенирования (FASTQ), полученный либо из NCBI SRA, либо сгенерированный для тестирования пайплайна

Также был загружен и проиндексирован референсный геном:

reference/ecoli.fa

3. Индексация референса

Референсный геном был проиндексирован с использованием BWA:

создан индекс для последующего выравнивания ридов

4. Bash-пайплайн

Реализован скрипт, который включает:

Контроль качества (FastQC)
Выравнивание ридов (BWA MEM)
Конвертацию SAM → BAM
Сортировку BAM
Получение статистики картирования (samtools flagstat)
Оценку качества картирования

5. Оценка качества картирования

На основе результата samtools flagstat вычислялся процент картированных ридов:

если mapped reads > 90% → результат OK
иначе → NOT OK

6. Разбор результатов flagstat

Написан скрипт (bash), который:

извлекает общее число ридов
извлекает число картированных ридов
вычисляет процент маппинга
выводит итоговое решение (OK / NOT OK)
